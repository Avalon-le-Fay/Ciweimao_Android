##  在线登录
- 建议走本地root或抓包token登录（HttpCanary,无需root）

账密登录有概率被服务器判定为风险账号会弹人机验证；被判为风险还有可能强制叫你去改密。

**已接入的登录方式（2.9.366 协议）：**

| 方式 | 接口 | 说明 |
|---|---|---|
| 手机号短信验证码登录 | `signup/login_v2` | `send_verify_code` 发码 → `login_v2` 登录 |
| 账号密码登录 | `signup/login`| 支持人机验证与二次验证码 |
| Token 导入 | — | 抓包获取 `account` + `login_token` + `reader_id` |
| 游客登录 | `signup/auto_reg_v2` | 生成匿名账号 |


**人机验证（极验 GT3）**：由 `signup/use_geetest` 判定；
需要时弹出极验窗口（`GeetestDialog`），结果随登录请求提交。
该判定值是动态风控结果，同一账号不同时刻可能不同。

  >1. 不要在短时间内重复进行登录退出操作
  > 
  >2. 短时间内一次性下载多本书会被检测异常流量导致封号; 具体数额不明

## 登录网络提示

**超时相关**

- 报错形如 `接口连接失败 @signup/login_v2: official libcurl request failed (curl=28: Error)`：
  官方 native 层（libcurl）超时。

  切IP，WIFI / 流量


**验证码相关**

- 同一手机号两次发码需间隔 **60 秒**：`请等待短信发送冷却结束`

- 服务器限流（错误码 `220008`）：`操作太频繁，请稍后获取短信验证码`

- 短时间多次请求验证码，IP 可能被临时封禁：**切换网络（换 IP）后重试**

- 验证码收不到：有效期 5 分钟，检查拦截/垃圾箱，或稍后重发



**人机验证（极验）**

 密码登录可能要求人机验证，会弹出原生极验窗口

 会话有效期 5 分钟，超时需重新发起登录
 同一账号不同时刻的风控判定可能不同（服务器动态决定）

**Token 导入**

- 需要 `account` + `login_token` + **`reader_id`**（`reader_id` 缺失会提示补充）
- `shelf_id` 可留空，启动后自动发现
